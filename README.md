# Yandex Mail Avatar Icons — 2025–2026 Color Variants

A collection of 30 reusable 32×32 SVG mail avatar icons based on the Yandex Mail-style avatar icon designs used and referenced in 2025–2026 email interface workflows.

The set includes two original icon variants (`b2b` and `b2c`) in 15 color themes each. Every SVG keeps the original dimensions, geometry, white symbol, and scalable vector format; only the background color treatment changes.

> This is an independent community resource. It is not affiliated with, sponsored by, or endorsed by Yandex. “Yandex Mail” is a trademark of its respective owner. The wording “Yandex Mail-style” describes the visual reference and search intent, not official ownership.

## What is included

- 15 `b2b` solid-color SVG avatars
- 15 `b2c` gradient-color SVG avatars
- 32×32 `viewBox` preserved in every file
- White mail/avatar symbol preserved in every file
- No raster images, JavaScript, or external dependencies

## Who can use these icons?

These icons are useful for:

- Developers building custom email clients and mail interfaces
- UI/UX designers who need ready-to-use mail avatar options
- Frontend developers looking for lightweight SVG profile icons
- Product teams prototyping inboxes, contact lists, and notification screens
- Anyone who has trouble choosing a mail icon and wants a consistent color set

They can be embedded directly in HTML, CSS, React, Vue, email prototypes, design systems, and other web interfaces.

## Usage

Download any SVG and use it as an image, CSS background, or inline SVG:

```html
<img src="ya-360-b2c-purple.svg" width="32" height="32" alt="Purple mail avatar icon">
```

## File naming

- `ya-360-b2b-<color>.svg` — solid background with a darker outline
- `ya-360-b2c-<color>.svg` — radial gradient background

Available colors: coral, red, rose, purple, violet, indigo, blue, cyan, teal, green, lime, yellow, orange, brown, and slate.
